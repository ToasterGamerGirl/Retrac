# Codename GRIDFALL

Konzept für ein eigenständiges Third-Person-Battle-Royale mit Bau- und Editiersystem auf Basis der Unreal Engine 5.

- [Game Design Document & technische Roadmap](docs/GDD.md)

Das Projekt verwendet ausschließlich eigene oder lizenzierte Inhalte. Es nutzt keine Assets, Marken oder Spieldateien anderer Spiele.
